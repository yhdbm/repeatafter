# Repeat After Me

Mobile-first Django app: hears a common sentence read aloud (male US English voice), you repeat it, it scores you word by word and highlights the words you got wrong or missed (red, with what it heard). Sentences you score poorly on come up more often.

## Run
    .venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
Open http://<PC-IP>:8000 on the phone (same Wi-Fi). Add more sentences in /admin (create a user with `manage.py createsuperuser`) or edit `practice/management/commands/seed_sentences.py` and re-run `manage.py seed_sentences`.

## Microphone needs HTTPS on a phone
Browsers only allow mic access on https:// or localhost. Options: tunnel with `cloudflared tunnel --url http://localhost:8000` (or ngrok), or in Chrome Android open chrome://flags, enable "Insecure origins treated as secure", add http://<PC-IP>:8000.

## How it works
- Speaking: natural Microsoft neural male voices via edge-tts (needs internet on the PC), generated by /api/tts/ and cached in 	ts_cache/. Pick the voice under "Voice & options". If the server voice fails, the phone's built-in voice is used.
- Listening: browser SpeechRecognition (en-US). Works in Chrome (Android) and Safari (iOS 14.5+).
- Tips: practice/tips.py gives per-word advice (-ed endings as T / D / extra syllable, silent letters, th, r, stress) and notices swallowed endings.
- Scoring: `practice/scoring.py` aligns target vs heard words (difflib). ok = 1, close (similar sound) = .75, wrong/missed = 0, small penalty for extra words.
- Attempts are stored in the `Attempt` model (see /admin).

- Phonetics: IPA (American English) comes from the CMU Pronouncing Dictionary via the cmudict package (practice/phonetics.py), shown with every tip. Saved words are under the ? Saved button in the header (also in /admin).
